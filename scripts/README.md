# ⚙️ Corpus EDA Scripts

**Utility scripts for the mailroom-corpus-eda package.**

## Scripts

| Script | Purpose |
|:---|:---|
| `generate_figures.py` | Generate static figures |
| `gen_interactive_charts.py` | Generate interactive charts |
| `run_all.py` | Run full EDA pipeline |

## Usage

```bash
cd packages/mailroom-corpus-eda
python scripts/run_all.py
python scripts/generate_figures.py
python scripts/gen_interactive_charts.py
```
